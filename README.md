# AralOne

اسکلت وب‌سایت ساختار ماژول‌های اپلیکیشن **AralOne** (آرال‌تک) — یک صفحه استاتیک با ۱۲ ماژول صنعتی، آماده‌ی استقرار روی GitHub Pages.

## ساختار پروژه

```
aralone/
├── index.html          # صفحه اصلی
├── styles.css          # استایل‌ها
├── modules.js          # داده ۱۲ ماژول (برگرفته از سند اصلی)
├── app.js              # رندر کارت‌های ماژول
└── .github/workflows/deploy.yml   # استقرار خودکار روی GitHub Pages
```

## اجرای محلی

هیچ نیازی به build یا نصب پکیج نیست؛ فقط `index.html` را در مرورگر باز کنید یا:

```bash
python3 -m http.server 8080
# سپس در مرورگر: http://localhost:8080
```

## دیپلوی روی GitHub Pages

### روش ۱ — از تنظیمات مخزن (ساده‌ترین راه)
1. این پوشه را در یک مخزن جدید در گیت‌هاب push کنید.
2. به `Settings → Pages` بروید.
3. در بخش **Source**، گزینه `Deploy from a branch` را انتخاب کنید.
4. Branch را `main` و پوشه را `/ (root)` انتخاب کنید و Save بزنید.
5. بعد از چند دقیقه سایت روی آدرس `https://<username>.github.io/<repo-name>/` در دسترس است.

### روش ۲ — با GitHub Actions (خودکار در هر push)
یک workflow آماده در مسیر `.github/workflows/deploy.yml` قرار داده شده است.
فقط کافی‌ست در `Settings → Pages → Source` گزینه `GitHub Actions` را انتخاب کنید؛ از آن پس با هر push روی `main`، سایت به‌طور خودکار منتشر می‌شود.

## افزودن ماژول جدید

برای اضافه یا ویرایش یک ماژول، کافیست آبجکت مربوطه را در `modules.js` اضافه یا تغییر دهید؛ رابط کاربری به‌صورت خودکار به‌روزرسانی می‌شود.

## اتصال به بک‌اند واقعی

این نسخه فقط رابط کاربری (front-end) است. برای اتصال هر ماژول به داده واقعی:
- یک API endpoint برای هر ماژول در بک‌اند خودتان بسازید.
- در `app.js`، به‌جای خواندن از `modules.js`، داده را با `fetch()` از API دریافت کنید.

این یک اسکلت آماده استقرار است

این نسخه یک اپلیکیشن کامل با بک‌اند واقعی (Node.js + Express + SQLite) است. هر ماژول صفحه اختصاصی خودش را دارد؛ داده‌ها ثبت، ویرایش و حذف می‌شوند و در پایگاه‌داده ذخیره می‌مانند.

cd backend && npm install && npm start برای اجرای بک‌اند و فرانت روی پورت ۴۰۰۰ کافی است.
